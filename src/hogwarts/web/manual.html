✧ 雾梣学期回到校园

一份写给新生的便笺

校园手册

第一次进入

在注册页填写名字，领取 hw_sk_ 开头的学生凭证。保存它，然后点起床。网页与 AI 可以用同一凭证行动，物品、已知事实和课程记录都会同步。另一位学生需要自己的凭证。

今天先做什么

起床 → 看课表 → 从校医院到礼堂 → 到图书馆 → 等到九点 → 签到魔咒课 → 对魔杖施放荧光闪烁 → 和教授交谈。三门课均在工作日开课；开课后十五分钟内到指定地点签到。

走路与探索

地点卡里的「可以前往」列出真正相连的出口。地图是方位图，不能隔空传送。图书馆通向禁书区，完成魔咒课后向教授申请许可。禁林只开放入口；霍格莫德只开放校界内摊位。

学魔咒

没有学过的魔咒不能练习或施放。上课会学会入门魔咒；也可带着练习册在图书馆学习。阅读目录不会直接学会咒语。练习提高熟练度，施法按熟练度与体力决定成败，失败也消耗体力。每个魔咒有合法目标，只有目标可见时网页才显示施放按钮。

吃东西、休息和交易

行囊中的苹果恢复十点体力，恢复药剂恢复三十点。它们会实际消耗。校医院可以休息。霍格莫德入口的塔文·铜枝出售药剂，每瓶五枚金币；可以在他的对话选项中购买。

宵禁与同校学生

二十二点至次日六点宵禁。留在外面的学生会被奥伦·石栎送回校医院，第一次被抓记录违规并扣五分。同一夜重复夜游仍会被送回。游戏采用行动推进的共用校园时间，大家等待、上课、睡眠都会推进时钟，巡查也会检查其他在外的学生。游戏不随真实时间自动运行。

秘密不会提前写出来

人物私密资料、后续线索和世界真相不会直接展示。交谈、阅读和搜索才能形成自己的见闻。某位学生发现的秘密不会自动写进你的档案。物体状态共用，别的同学解锁的练习箱，你也可以观察，但仍须自己搜索才获知内容。

给 AI 的入口

点「复制 AI 接入地址」，把地址配置为 Streamable HTTP MCP。也支持地址 /mcp/ 配合 Authorization: Bearer 凭证。工具精确为 look、move、inspect、talk、ask、give、check_status、check_schedule、check_inventory、attend_class、study、practice_spell、cast_spell、use_item、read、search、sleep、wait。

当前 NPC 使用固定回复和持久记忆，人物与故事原创。每次成功行动自动保存；服务器重启后继续原档。没有管理员修改工具，也没有从文字中直接加金币或学咒的捷径。
